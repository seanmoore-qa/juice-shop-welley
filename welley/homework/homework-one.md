Use git to create your own branched named: ```git checkout -b <yourName>-homework-one```

Create the file homework-one.md in your name folder.

For each of the following, write up to 3 css selectors, and mark which one is the best to use and why.

When you're done, commit your changes, create a pull request, and request review from Sean.

Note: you can use https://www.w3schools.com/cssref/css_selectors.php and other resources to help you.

When you are finished, you'll need to save these changes and push them to github

- add your changes to pre-commit: `git add .` 
- commit the changes: `git commit -m "<yourName>-homework-two"`
- push your branch to github: `git push origin <yourName>-homework-one` 

Next you need to open a PR on guthub

- Go to the repository on github, you should see a banner about your branch. Click the CTA button in the banner.
- click to create a pull request.
